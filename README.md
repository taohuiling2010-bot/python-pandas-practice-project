# 基于 Python 的非结构化数据清洗与分析链路构建（以影视数据为例）

> 基于 Python 爬虫 + Pandas 数据清洗 + Matplotlib 可视化的端到端项目：把网页上抓下来的半结构化文本，加工成可以直接分析的标准数据，并用断言校验每一步清洗没有引入新的错误。

## 📌 项目定位

本项目作为**数据分析能力练习项目**，重点展示以下技术能力：

- **数据采集**：使用 requests + lxml.etree 实现网页数据爬取与 HTML 解析
- **数据清洗**：先做数据质量画像，再用正则表达式完成字段标准化、截断字段识别、多值字段拆分，每一步附断言校验
- **统计分析**：分组聚合、多值标签频次统计、Pearson 与 Spearman 相关性交叉验证
- **数据可视化**：使用 Matplotlib 制作多维度图表，呈现数据规律

数据题材选择豆瓣电影 Top250 是出于**数据获取的合规性**与**字段维度的丰富性**考虑，
本项目所演示的数据处理方法可迁移至任何业务场景的数据分析工作。

## 🎯 核心工作

1. **数据采集**：使用 Python 爬虫获取 250 部电影 × 9 个字段（共 2238 个非空数据点），实现非结构化网页数据的结构化存储
2. **数据质量画像**：清洗前逐列检查类型、缺失与问题样例，形成"问题—处理方式"清单
3. **数据清洗**：用正则表达式提取年份与中文人名、识别并剔除被截断的不完整名字、拆分多值字段；6 类问题全部附断言校验，清洗后 250 部电影无一删除
4. **统计分析与可视化**：围绕 5 个业务问题做频次统计与相关性分析，用 Pearson 与 Spearman 两种系数交叉验证结论

---

## 💡 核心成果

- **识别截断数据**：发现豆瓣列表页的主演、导演字段被截断，**74 个只剩半截的名字**（如"陈""西恩""凯特·布"）会被误当成真人统计；按截断位置区分处理后剔除
- **交叉验证相关性**：评分与评价人数的 Pearson 相关系数为 0.31，但 Spearman 秩相关系数仅 0.11；按评分分档后发现，只有 9.3 分以上的头部电影评价人数明显更多，0.31 主要由少数极端值拉高
- **复盘类型转换陷阱**：早期版本把评分误转为整数，14 档评分被压成 2 档，相关系数被低估；现已加入类型断言防止复发
