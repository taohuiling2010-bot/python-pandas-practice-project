# 零售连锁企业收入质量分析与折扣管控可视化项目
1.	项目周期：2026.04 - 2026.05
2.	项目角色：独立负责人
3.	核心技术栈：MySQL、Power BI（DAX/数据建模）
4.	项目背景：模拟连锁零售业务真实场景，基于销售订单、商品、会员、门店、品类多源数据，构建"吊牌额-促销折扣-会员折扣-实际收入"四层收入结构模型，搭建 4 大可视化看板支撑收入质量监控与折扣策略优化决策。

## 核心工作：
1.	通过 6 段 SQL 完成数据加工，输出大区收入质量、门店折扣对标、商品贡献度、会员价值、品类结构、当日运营 6 大主题分析数据集；
2.	在 Power BI 中构建覆盖收入、折扣、客户经济性等 4 大类、20+ 项核心指标的财务指标体系，编写 25+ 项 DAX 度量值，落地 MTD/MoM 双口径时间对比框架；
3.	搭建 4 页可视化看板：收入质量驾驶舱、折扣结构拆解、门店收入对标、商品&会员价值分析，重点设计收入瀑布图、商品贡献度散点图、会员价值矩阵等核心视觉对象。

## 核心成果：
1.	数据治理：在数据清洗阶段识别 POS 系统将营销发券记入销售明细的数据质量问题（"苏泊尔压力锅优惠券"销售额为0），通过商品维度过滤剥离非销售记录，提升了滞销分析的准确性；
2.	财务洞察：通过会员折扣率分析（会员综合折扣率 5.86% 是非会员 2.73% 的 2.14 倍，但会员客单价仅高出 14.5 元），定位会员体系的"高购买力+高让利"双高现象，为评估会员折扣力度是否过度提供数据支撑；
3.	商品管控：识别 100 个零销售 SKU（占商品池约 18%）和 7 个高折扣依赖商品，为清库决策与差异化定价策略提供量化依据；
4.	落地"数据采集-加工-可视化-业务洞察"完整数据分析闭环，建立可复用的零售财务分析模板。
